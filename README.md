### Trabajo practico de programación funcional  

Este es un trabajo practico de la cátedra de Paradigmas de la Programación (PPR) de la universidad 
en la que estudio ingeniería en sistemas de información. Se trata de un programa en haskell diseñado
para generar informes de pólizas que se hacen sobre los autos de los clientes de un negocio.
El programa ofrece las funciones que se utilizan para realizar los cálculos de las pólizas.
